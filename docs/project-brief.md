# Checkout Scout Project Brief

Checkout Scout is a community-updated price discovery app.

It helps users find estimated local prices before visiting a store or making a purchase decision.

## Product Positioning

Checkout Scout is not a marketplace.

It does not support:

- carts
- payments
- orders
- delivery

## Core Value

Users can search for an item and see:

- stores that may carry it
- reported price
- last confirmed date
- price confidence
- community reports
