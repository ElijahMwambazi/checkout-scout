# User Flows

## Browse Price

1. User searches for product.
2. App shows matching products.
3. User opens product page.
4. App shows reported prices by store.
5. User checks last confirmed date and confidence.

## Submit Price

1. User opens submit price page.
2. User selects product and store.
3. User enters observed price.
4. Optional proof image or notes.
5. Submission enters moderation queue.

## Confirm Price

1. User opens product price.
2. User clicks confirmed, changed, or out of stock.
3. Confidence score updates.
